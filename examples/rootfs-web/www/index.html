Local web example · Exemplo web local

This page is included in the Esquema demo rootfs. When launched with examples/deploy-web.scm, BusyBox serves it from a container that shares the host network and uses compatibility mode. Cgroup limits are best-effort. The page alone does not verify the server's isolation.

Replace examples/rootfs-web/www/index.html with your content. Set ESQ_PORT to choose a port; the default is 8081.
