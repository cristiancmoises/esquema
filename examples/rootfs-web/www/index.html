SERVED FROM INSIDE AN ESQUEMA CONTAINER

Esquema 🔥

A minimal, security‑first, rootless container runtime built natively in Scheme for GNU Guix — no daemon, no root, no YAML. This very page is being served by busybox httpd running as PID 1 in an isolated Esquema sandbox.

;; a container is a first-class Scheme value
(run-container
  (make-container "web" rootfs '("/bin/busybox" "httpd" "-p" "81"))
  ;; secure by default: userns · seccomp · caps dropped)

Rootless userns

Runs as your ordinary user; root only inside the namespace.

Full isolation

mount · pid · uts · ipc · net · cgroup namespaces + pivot_root.

seccomp‑BPF

Syscall allowlist; TIOCSTI / ptrace / mount killed.

No capabilities

Bounding set emptied, securebits locked, no_new_privs.

cgroups v2

Best‑effort memory · pids · cpu limits.

~13 ms start

All of it in async‑signal‑safe C between fork and execve.
