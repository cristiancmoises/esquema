01 / Overview

Containerization that stays in the Guix language.

Esquema keeps the workload, isolation policy and resource limits in Scheme. A container is a first-class value rather than a YAML document sent to a privileged service.

01 — DECLARATIVE

Scheme from definition to runtime

Use make-container, keyword arguments and ordinary Guile composition. Generate containers, share functions and keep policy beside system configuration.

02 — ROOTLESS

No host root required

The payload can appear as UID 0 inside its user namespace while mapping back to the invoking ordinary user outside.

03 — DAEMON-FREE

No always-on privileged control plane

The calling process creates the sandbox, executes the payload, waits for it and returns the exit status.

04 — REPRODUCIBLE

Designed around GNU Guix

Use the manifest and Guix store paths. To reproduce dependencies, pin the channel revisions too: the manifest alone does not pin them.

05 — EXPLICIT

Isolation is visible in code

Namespaces, mounts, environment, hostname, seccomp, capability handling, rootfs mode and limits are represented directly.

06 — SMALL

Thin Guile layer, hardened C primitives

Guile provides the declarative interface while low-level namespace and security setup is performed by a focused C library.

02 / Esquema 0.3.0

Explicit policies. Verifiable requirements.

Compatibility mode attempts cgroup and Landlock setup. Strict mode requires the configured protections. Containers share the host Linux kernel.

01

Namespaces and identity

Seven namespaces by default. Internal uid 0 maps to the host user; capabilities are removed and no_new_privs is set.

02

Version-1 seccomp policy

Validates architecture, socket families, io_uring and ioctl. Dangerous syscall denials are fatal; non-native ABIs are rejected.

03

Landlock and descriptors

Confines handled access to the new root. Descriptors above 2 close unless explicitly delegated. Landlock cannot revoke already-open descriptors.

04

Verified resource limits

Strict mode requires delegated cgroups v2, at least one cgroup limit and version-1 RLIMIT_NOFILE. Setup failures abort the launch.

05

Mounts and rootfs

Bind destinations reject traversal. Strict mode requires the necessary mount APIs; a strict read-only root requires recursive application and readback.

06

PID-1 supervision

Forwards signals, reaps descendants and escalates TERM to KILL after the timeout. Automatically enabled in strict mode.

Scheme · strict / Fortress
(use-modules (esquema runtime) (esquema container))

(exit
 (run-container
  (make-container "worker" "/absolute/path/to/rootfs"
                  '("/bin/sh" "-c" "echo confined")

Example: 256 MiB, 128 processes, 50% of one CPU and 1024 open files. The rootfs must contain /bin/sh and its dependencies. This configuration requires Landlock, delegated cgroups and suitable mount APIs. Read the policy boundaries.

Run the web demonstration.

The repository example runs BusyBox httpd in a container on port 8081. This public site is distributed as static HTML; its hosting is not evidence of runtime isolation.

Guix · BusyBox
guix shell -m manifest.scm -- make smoke
BUSYBOX="$(guix build busybox)/bin/busybox" \
  sh examples/build-web-rootfs.sh examples/rootfs-web
ESQ_PORT=8081 guix shell -m manifest.scm -- \
  env ESQUEMA_LIBDIR="$PWD" guile -L scheme examples/deploy-web.scm
In another terminal
curl --fail http://127.0.0.1:8081/
Place content in examples/rootfs-web/www/. ESQ_ROOTFS overrides the script-relative rootfs; ESQ_PORT chooses the port. This example shares the host network, uses compatibility mode and applies cgroups on a best-effort basis. The read-only /gnu/store bind exposes its readable contents.

For public HTTPS, configure a reverse proxy and access rules. The example serves HTTP and may listen on all host interfaces.

Where Esquema fits.

A library for container policies in Scheme, with Guix integration and direct Linux installation.

01

Linux

Namespaces, seccomp and Landlock are Linux APIs. BSD, macOS and Windows require a Linux VM; native support is not implemented.

02

Scheme + C

Compose configurations in Guile. The C library handles low-level setup and exposes a public API.

03

Rootfs

Prepare the executable and dependencies in a directory. The runtime does not pull OCI images or provide a Docker-compatible CLI.

09 / FAQ

Operational answers.

The most important distinctions before deploying a workload.

Is UID 0 inside the container host root?

No. With the default user namespace, UID 0 inside maps to the invoking ordinary UID outside. The capability set is also emptied and securebits/no-new-privileges controls prevent UID 0 from regaining normal root semantics.

Why is the web server unreachable with the default namespace list?

The default includes a private network namespace, so the workload sees loopback rather than the host interfaces. A host-reachable deployment deliberately omits net, or must add an explicit networking mechanism.

Can Esquema replace a VM for hostile code?

No blanket equivalence should be assumed. Esquema adds strong container controls but shares the Linux kernel. Use a VM or microVM when the threat model requires a separate kernel boundary.

Why mount /gnu/store for the BusyBox demo?

The Guix BusyBox binary is dynamically linked and needs its loader and libraries. Mounting the store read-only resolves them. A statically linked web server removes that dependency and narrows visibility.

Does cgroups v2 always enforce the requested limit?

Compatibility mode provides no mandatory guarantee. Strict mode verifies requested limits and aborts startup if delegation or enforcement fails.

Does this page contain JavaScript or external assets?

No. It is one HTML file with embedded CSS, a data-URI favicon and no external requests. All animation is CSS and is disabled when the user requests reduced motion.
